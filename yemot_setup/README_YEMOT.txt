הוראות הגדרת שלוחה 3 בימות המשיח:
=====================================================

1. היכנסו למערכת הניהול של ימות המשיח.
2. עברו לשלוחה 3.
3. הגדירו את קובץ התצורה לפי ext.ini שבתיקייה זו.
4. החליפו את כתובת השרת ב-api_url לכתובת Render האמיתית בתוספת /yemot.
5. העלו לשלוחה 3 את M0000.wav ואת M1000.wav.
6. שמרו ובדקו את הקו.

הסקריפט האוטומטי תומך במספר שלוחה כארגומנט האחרון:
node yemot_setup/auto_setup_yemot.js <YEMOT_TOKEN> <RENDER_URL> 3
