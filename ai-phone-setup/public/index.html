בינה טלפונית AI

מחברים ארבעה חשבונות, לוחצים פעם אחת, ומחייגים לדבר עם הבינה.

המפתחות עוברים רק לשירותים עצמם ולא נשמרים אצלנו.

1

GitHub

איך מתחברים
התחברות עם GitHub

יפתח מסך אישור של GitHub. לוחצים Authorize ומוחזרים לכאן.

  1. התחברו ל-GitHub (או הירשמו), ואז לחצו על הכפתור למטה.
  2. ייפתח דף יצירת אסימון עם ההרשאה repo כבר מסומנת (נדרשת ליצירת מאגר פרטי) ועם השם ai-phone-setup. אם GitHub מבקש סיסמה, הזינו אותה.
  3. בתחתית הדף לחצו Generate token.
  4. העתיקו מיד את האסימון (מתחיל ב-ghp_). הוא מוצג פעם אחת בלבד.
  5. הדביקו כאן ולחצו אימות טוקן. תופיע הודעה "מחובר".
פתיחת יצירת טוקן ב-GitHub
2

Render

איך משיגים מפתח
  1. לחצו על הכפתור למטה. היכנסו ל-Render או הירשמו (אפשר להירשם עם GitHub).
  2. לחצו על סמל הפרופיל בפינה הימנית העליונה ← Account Settings.
  3. גללו למטה עד הסעיף API Keys ולחצו Create API Key.
  4. תנו שם (למשל ai-phone) ולחצו שוב Create API Key.
  5. העתיקו מיד את המפתח (מתחיל ב-rnd_). הוא מוצג במלואו פעם אחת בלבד. הדביקו אותו כאן.
פתיחת Render
חובה לפני ההקמה (במיוחד למאגר פרטי):
  1. ב-Render בהגדרות החשבון בסעיף Git Deployment Credentials התחברו ל-GitHub.
  2. ב-GitHub פתחו את הקישור למטה, בחרו את Render ← Configure ← Repository access ← All repositories ← Save.
הרשאות אפליקציות ב-GitHub
3

ימות המשיח

איך משיגים מפתח ושלוחה
  1. היכנסו לאתר הניהול של ימות המשיח ועברו ללשונית אבטחה ← ניהול מפתחות גישה.
  2. צרו מפתח API חדש, והעתיקו אותו. מפתח כזה קבוע ופטור מאימות דו-שלבי.
  3. אל תגבילו אותו בחומת האש (או אפשרו לו את השירותים GetSession, UpdateExtension, GetTextFile).
  4. בחרו מספר שלוחה פנוי (למשל 9). האתר יהפוך אותה לשלוחת API.
אתר הניהול של ימות המשיח ניהול מפתחות (חומת אש)
אם השלוחה כבר בשימוש, ההגדרות שלה ישתנו לשלוחת API. בחרו שלוחה ריקה.
4

הבינה המלאכותית

איך משיגים מפתח

בחרו ספק בתפריט למטה. יופיעו כאן ההוראות המדויקות שלו.

  1. היכנסו עם הכפתור, התחברו או הירשמו.
  2. בדף API keys לחצו Create new secret key.
  3. תנו שם ולחצו Create.
  4. העתיקו מיד את המפתח (מתחיל ב-sk-). הוא מוצג פעם אחת בלבד.
  5. נדרש יתרה בחשבון (Billing) כדי שהמפתח יעבוד.
פתיחת מפתחות OpenAI
  1. היכנסו עם הכפתור, התחברו או הירשמו.
  2. עברו ל-Settings ← API Keys ולחצו Create Key.
  3. תנו שם והעתיקו מיד את המפתח (מתחיל ב-sk-ant-). הוא מוצג פעם אחת בלבד.
  4. נדרש קרדיט בחשבון (Billing) כדי שהמפתח יעבוד.
פתיחת מפתחות Anthropic
  1. לחצו על הכפתור למטה והתחברו עם חשבון גוגל.
  2. אם מופיעים תנאי שימוש, אשרו אותם.
  3. לחצו Create API key.
  4. אם מבקשים לבחור פרויקט, בחרו פרויקט קיים או צרו חדש (נוצר אוטומטית).
  5. העתיקו את המפתח (מתחיל ב-AIza) והדביקו כאן. אפשר לראות אותו שוב באותו דף בכל עת.
  6. יש מסלול חינמי ללא חיוב, אבל עם מגבלת בקשות לדקה. אם החשבון מנוהל על ידי ארגון או בית ספר, ייתכן שיצירת מפתח חסומה.
פתיחת מפתחות Gemini

אחרי שבחרתם מודל והדבקתם מפתח, האתר בודק לפני ההקמה שהם עובדים.
